# power-bi-dashboard-portfolio

A collection of Power BI dashboards created to demonstrate practical skills in **data modelling, Power Query, DAX, KPI development, data visualization, and interactive dashboard design**.

> **Note:** The dashboards use practice/sample data and are intended to demonstrate Power BI development and visualization skills.

## Dashboards

### 1. Sales Analysis Dashboard

Interactive dashboard presenting sales performance through KPIs, customer-level sales, profit margins by product category, and monthly sales trends.

**Skills demonstrated:**

* KPI development
* DAX measures
* Sales and profitability analysis
* Data visualization
* Interactive dashboard design

### 2. Supermart Sales Dashboard

Interactive sales dashboard covering total sales, profit, orders, customers, quantity, yearly sales trends, sales targets, channels, states, categories, salespeople, and stores.

**Skills demonstrated:**

* Data modelling
* DAX
* KPI cards
* Trend analysis
* Geographic visualization
* Interactive filtering

### 3. Sales Data Analysis

Dashboard analysing quantity, sales, cost, profit, profit margins, brands, product categories, and state-level sales performance.

**Skills demonstrated:**

* Data modelling
* DAX measures
* Profitability analysis
* Category and brand analysis
* Data visualization

### 4. HR Analysis – Attrition Report

HR dashboard analysing employee workforce composition, salary, age, active and separated employees, attrition, departments, employee bands, and overtime.

**Skills demonstrated:**

* HR analytics
* KPI development
* Attrition analysis
* Data visualization
* Interactive slicers
* Comparative analysis

### 5. Connectivity Analysis Report

Dashboard analysing population, subscribers, states, regions, growth, penetration rates, and internet, mobile, and telephone subscribers.

**Skills demonstrated:**

* KPI development
* Trend analysis
* Geographic visualization
* Interactive filtering
* Data visualization

## Tools & Technologies

* **Microsoft Power BI**
* **Power Query**
* **DAX**
* **Data Modelling**
* **Data Visualization**
* **Interactive Dashboards**
* **KPI Development**

## Purpose

These dashboards were created as hands-on practice to develop and demonstrate practical **Business Intelligence and data visualization skills using Microsoft Power BI**.
